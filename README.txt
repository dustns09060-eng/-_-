적용 방법
1. ZIP 압축을 풉니다.
2. GitHub 저장소 기존 파일을 전부 교체합니다.
3. Commit changes를 누릅니다.
4. 사이트 주소 뒤에 ?v=244를 붙여 접속합니다.
5. 이전 화면이 보이면 브라우저 캐시를 삭제하거나 시크릿 모드에서 확인합니다.
